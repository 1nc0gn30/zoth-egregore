If synthesis fails, the lead cluster's medoid is returned.

FAQ

          
Frequently Asked Questions

        


        

          

            Does EGREGORE burn 1,000 API calls on simple questions?
            

              No. Adaptive mode starts with a single 8-mind seed wave (deepseek/deepseek-v4.1-flash) and computes exact Beta-posterior consensus 1 - I_0.5(V_1+1, V_2+1) locally with zero judge calls. When the 8 minds agree, EGREGORE stops immediately at 8 scout calls + 1 synthesis call. Only genuine disagreement earns larger waves.
            

          

          

            How does EGREGORE authenticate with DeepSeek Flash and Nous Hermes?
            

              On machines with Nous Hermes Agent installed, EGREGORE automatically discovers your Nous Portal credentials in ~/.hermes/auth.json. You can also set NOUS_API_KEY, DEEPSEEK_API_KEY, or OPENROUTER_API_KEY via environment variables without changing code.
            

          

          

            What happens if I use EGREGORE without ZothOS or Zoth Studio installed?
            

              The core deliberation engine, 3,456 co-prime Pantheon lenses, Adaptive-Consistency stopping, and Design+Logic Codex work 100% standalone on Python 3.10+. Installing Zoth Studio or running on ZothOS upgrades egregore/zoth_tools.py from specification hints to live local CLI & loopback daemon orchestration across 77 tools.
